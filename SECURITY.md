# Security Policy

## Supported Versions

We currently provide security updates only for the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability (such as exposed API keys, flaws in authentication, or Firestore rule leaks), please **do not** open a public issue.

Instead, please report it via one of the following methods:

1. **GitHub Private Vulnerability Reporting:** Go to the **Security** tab of this repository $\rightarrow$ Click **Report a vulnerability**.
2. **Direct Contact:** Send an email to `bekz.alt228@gmail.com`.

### What to include in your report:
- A clear description of the issue.
- Steps to reproduce the bug or vulnerability.
- Proof of concept (if applicable), without exploiting the issue.

We will acknowledge your report within 48 hours and work on a fix as soon as possible.
